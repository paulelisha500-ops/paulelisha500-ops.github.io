# Certificates

Drop certificate files in this folder and they appear on the site's Certificates page on the next deploy.

- **Image** (PNG, JPG, WebP) shows as the preview; a **PDF** with the same name is linked as the full document.
- Name files after the certificate, e.g. `aws-machine-learning.png`; that becomes the title "Aws Machine Learning".
- To set a proper title, issuer, date or verification link, add an entry in `src/data/certificates.ts`.

From the GitHub website: open this folder → **Add file** → **Upload files** → **Commit changes**.
